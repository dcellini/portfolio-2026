## The problem

I picked up manager and organisation reports mid-project. A lot was already built, but it needed active debugging, and new features on top.

Large reports could time out before they finished, and some surveys were producing no key drivers at all.

## What I did

- Fixed how key-driver data passed between the platform and the Python/R analysis. Scaled questions were being filtered out by mistake, which produced zero key drivers.
- Added driver-level selection to report configuration, and permission-based logic so managers see team or organisation key drivers depending on their permissions.
- Added support for grouped attributes when generating reports, turned report creation on by default for managers, and fixed an eNPS attribute bug on surveys with no key drivers.
- Made AI narrative generation for organisation reports, on AWS Bedrock, run concurrently, on top of reliability fixes to the reporting Lambda.
