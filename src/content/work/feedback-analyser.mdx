## Why I built it

I use AI tools every day, and I wanted to understand how to build reliable software around large language models, not just how to write prompts.

So I built a small employee-feedback analyser, one concept at a time, and wrote up what I learned as I went.

## What it does

- **Feedback analysis:** finds the sentiment, themes and priority of a comment, and summarises it.
- **Evaluation:** measures how accurate the analyses are, with deterministic checks, semantic checks and an LLM acting as judge.
- **Semantic search and RAG:** finds feedback by meaning rather than exact words, and uses it to answer questions with sources.
- **Tool calling and an agent:** lets Gemini request approved TypeScript functions, over several steps, to answer harder questions.
- **Grounding:** checks quotes, source references and numerical claims against the evidence before an answer is shown.
- **Privacy:** redacts email addresses and UK mobile numbers.

## How I built it

- Treated every AI response as untrusted data, validated with Zod before it's used.
- Kept the workflows independent of the AI provider, with dependency injection and mock providers, so the tests never call a live model.
- Covered it with automated tests in Vitest, for both the API and the React front end, checked in GitHub Actions on every push.
- Built the HTTP API twice, once with Express and once with no framework, to understand what Express does for you.
